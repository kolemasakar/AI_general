У каталозі **111 позицій**. Вихідні 48 нагород зберігають свій відносний порядок, 63 додано. Остання підтверджена збірка містить зображення для **55 позицій**, для **56 позицій** зображення ще не вдалося верифікувати/одержати.

**Вимоги до зображень:** за останнім розпорядженням власника обмеження щодо роздільної здатності, 600 ppi й прозорості зняті. Зображення мають відповідати назві нагороди; ілюстрації інших нагород, посвідчень та декоративних стрічок як заміну не використовувати.

**Першочергові державні джерела:**
- https://www.nas.gov.ua/derzavni-nagorodi — ілюстрації орденів і державних медалей
- https://mod.gov.ua/explanation/zaohochuvalni-vidznaki-ministerstva-oboroni — відомчі медалі та знаки
- https://mod.gov.ua/explanation/pochesni-nagrudni-znaki-golovnokomanduvacha-zbrojnih-sil-ukrayini — знаки Головнокомандувача
- https://asv.mil.gov.ua/awards/medal-za-viyskovu-sluzhbu-ukrayini — окрема нагорода (доступність для автоматичного завантаження обмежена)
- https://www.president.gov.ua/documents/5992026-60357 — орден Європи (зображення на сторінці, автоматичне завантаження заблоковане)
- https://zakon.rada.gov.ua/laws/show/1549-14 — законодавча основа

**Журнали походження зображень:** image_sources.csv, image_sources_nas.csv, image_sources_asv.csv, image_sources_president.csv, image_sources_commons.csv, image_sources_wikipedia.csv, image_sources_english.csv. Додані лише отримані зображення, недоступні офіційні файли не підмінено вигаданими.
