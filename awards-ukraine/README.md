# Каталог нагород України

Статус: підготовка каталогу на основі наданого PDF «Нагороди перелік NT.pdf».

Вимоги: незмінність складу та взаємного порядку початкового переліку; додавання відсутніх позицій; DOCX (№ з/п, назва, зображення); окремі файли зображень, бажано з прозорим фоном, від 945 px завширшки (для друку 4 см при 600 ppi).

Важливо: первинний документ містить як державні нагороди, так і відомчі відзнаки МОУ, Головнокомандувача ЗСУ та ГУР. Не слід ототожнювати всі ці категорії з державними нагородами у значенні Закону України «Про державні нагороди України».

Офіційні джерела для перевірки:
- https://mod.gov.ua/explanation/zaohochuvalni-vidznaki-ministerstva-oboroni
- https://mod.gov.ua/explanation/pochesni-nagrudni-znaki-golovnokomanduvacha-zbrojnih-sil-ukrayini
- https://zakon.rada.gov.ua/laws/show/1549-14

До підтвердження роздільної здатності й справжності зображень каталог не позначати завершеним.
